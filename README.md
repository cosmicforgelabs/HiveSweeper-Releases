# HiveSweeper

A Windows endpoint inspection and app-removal toolkit for IT administrators.

**Download:** [HiveSweeper.exe (latest)](https://github.com/cosmicforgelabs/HiveSweeper-Releases/releases/latest/download/HiveSweeper.exe) · Windows 10 / 11

## Verify your download

Each release lists the SHA-256 hash of `HiveSweeper.exe` in its release notes. After downloading, check it matches:

```powershell
Get-FileHash .\HiveSweeper.exe -Algorithm SHA256
```

HiveSweeper also verifies this hash itself before installing any of its own updates.

This repository hosts release downloads only. The source code is not published.
